Given an array height where each element represents the height of a vertical line, find two lines that, together with the x-axis, can contain the maximum amount of water.

Input: height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
Output: 49


Approach #1 Brute Force
------------------------

-> Use two nested loops
-> outer loop starts with index 0 and inner loop starts with i+1
-> for each pair find minHT, width and calculate area and find maxArea and return maxArea at last

TC - two nested loops - O(N2) i.e. n square
SC - O(1) constant i.e. not using any extra DS.
#code

function maxWater(arr){

  let maxArea = 0;

  for(let i=0;i<arr.length;i++){
    for(let j = i+1;j<arr.length;j++){
      let minHt = Math.min(arr[i],arr[j]);
      let width = j-i;
      let area = minHt * width;
      maxArea = Math.max(area, maxArea);
    }
  }

  return maxArea;
}

console.log(maxWater([1, 8, 6, 2, 5, 4, 8, 3, 7]));


Approach #2 Two Pointer
--------------------------

-> we need to find max area and we have length wch is height and width, so we will be using 2 pointer approach
-> left will start from 0th index and right will start from end of array index
-> We will iterate source arr and find minHt, width, area and maxArea like brute force approach
-> but we will not calculate it for all pairs

#intution
-> whatever pointer index val is less we will increment that only. This will find chance to find next larger height
-> and if both left and right values are same then increment any pointer wch is covered in else case.

#code

function maxWater(arr){

  let maxArea = 0;
  let left = 0;
  let right = arr.length-1;

  while(left < right){
      let minHt = Math.min(arr[left],arr[right]);
      let width = right-left;
      let area = minHt * width;
      maxArea = Math.max(area, maxArea);

    if(arr[left] < arr[right]){
      left++;
    }else{
      right--;
    }
  }

  return maxArea;
}

console.log(maxWater([1, 8, 6, 2, 5, 4, 8, 3, 7]));

TC - O(N)
SC - O(1) constant
