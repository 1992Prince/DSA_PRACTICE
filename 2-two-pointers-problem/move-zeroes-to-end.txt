Core Intuition
----------------

- All elements before the first zero are already in their correct places: If an array starts with [1, 5, 3, 0...], the first three numbers do not need to move at all.   

- j always marks the first available zero: Once j is placed at the first 0, any non-zero element found later by i can simply swap places with arr[j].   


- The zero naturally rolls forward: When you swap arr[i] (a non-zero number) with arr[j] (a zero), that zero moves to index i, and index j receives the correct number. Incrementing j (j++) ensures j immediately lands on the next zero in line.  



Step-by-Step Breakdown
------------------------

Step 1: Find the first zero (j)   

	Initialize j = -1.   
	Iterate through the array from 0 to n - 1.   
	The moment you see arr[i] == 0, 
	assign j = i and break immediately.   
	(Edge case: If j == -1 after the loop, the array has no zeroes at all, so return early.)

Step 2: Iterate and Swap   

	Start a pointer i from j + 1 up to n - 1.   
	Whenever arr[i] != 0:   
		swap(arr[i], arr[j])   
		j++   
	If arr[i] == 0, simply continue (i moves forward, j waits).

PSEUDO CODE  and ALGORITHM
------------------------------

ALGORITHM:

- Find the first zero in the array:

	Initialize j = -1

	Traverse the array from index 0 to n - 1

	If arr[i] === 0, set j = i and break

- If no zero is found (j === -1), return the array directly.

- Iterate pointer i from j + 1 to n - 1:

	- If arr[i] !== 0:

		- Swap arr[i] and arr[j]

		- Increment j (j++)

	- Return the modified array.

PSEUDOCODE:

function moveZeroes(arr, n):
j = -1

// Step 1: Find the first 0
for i from 0 to n - 1:
    if arr[i] == 0:
        j = i
        break
        
// If no zeroes are in the array
if j == -1:
    return arr
    
// Step 2: Swap non-zero elements into index j
for i from j + 1 to n - 1:
    if arr[i] != 0:
        swap(arr[i], arr[j])
        j++
        
return arr



CODE
-----

// Step 1: Find index of the first zero
for (let i = 0; i < n; i++) {
    if (arr[i] === 0) {
        j = i;
        break;
    }
}

// Edge case: If there are no zeroes, array is already done
if (j === -1) return arr;

// Step 2: Shift non-zeroes forward via swaps
for (let i = j + 1; i < n; i++) {
    if (arr[i] !== 0) {
        // Swap arr[i] and arr[j]
        let temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
        
        j++;
    }
}

return arr;

Core Intuition

- To move all zeroes to the beginning while keeping the relative order of non-zero numbers, you simply reverse the direction of traversal: scan from right to left instead of left to right.

- Find the last zero from the right: Everything to the right of this zero is already a non-zero element in its correct place.

- j points to the available zero slot: Moving backwards, whenever i encounters a non-zero number, swap it with arr[j] and decrement j (j--).

- This pushes all non-zero numbers toward the end of the array and packs zeroes to the front.
