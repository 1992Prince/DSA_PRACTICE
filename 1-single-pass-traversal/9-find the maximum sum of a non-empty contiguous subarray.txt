Given an array of integers, find the maximum sum of a non-empty contiguous subarray.

Input: arr = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
Output: 6


Approach #1 brute force
-------------------------

1) Find all possible subarrays using nested loops

We need to find all possible contiguous subarrays, and we can generate them using two nested loops.


let arr = [1, 2, 3];

for (let i = 0; i < arr.length; i++) {
    for (let j = i; j < arr.length; j++) {
        
    }
}

- `i` represents the starting index of the subarray.
- `j` represents the ending index of the subarray.
- For each `i`, we increment `j` from `i` to the last index.
- This generates all possible contiguous subarrays, where elements are in consecutive order from index `i` to index `j`.

For example, `arr = [1, 2, 3]` generates `[1]`, `[1, 2]`, `[1, 2, 3]`, `[2]`, `[2, 3]`, and `[3]`.

2) Calculate the sum of each subarray using a third loop

The first two loops only select the starting and ending indices. To calculate the sum of the selected subarray, we need another loop that iterates from index `i` to index `j` and adds each element to `sum`.


function maxSum(arr){

  let maxSum = -Infinity;

  for(let i=0;i<arr.length;i++){
    for(let j=0;j<arr.length;j++){

      let sum = 0;
      for(let k=i;k<=j;k++){
        sum += arr[k];
      }

      if(sum > maxSum){
        maxSum = sum;
      }
    }
  }

  console.log(maxSum);
}

maxSum([-2, 1, -3, 4, -1, 2, 1, -5, 4]) // 6


- `k` iterates from `i` to `j`, including both indices.
- `sum += arr[k]` adds each element of the selected subarray to `sum`.
- After calculating the sum, we compare it with `maxSum`. If the current sum is greater, we update `maxSum`.

3) Complexity

- Time complexity: `O(n³)` because we use three nested loops.
- Space complexity: `O(1)` because we use only a few variables and do not store all the subarrays.

Approach #2 single pass traversal 


intution
---------
1. Start adding array elements to sum to calculate the sum of a contiguous subarray.
2. After every addition, compare sum with maxSum and update maxSum if the current sum is greater.
3. If sum becomes negative, discard the current subarray by resetting sum = 0. A negative running sum will only reduce the sum of a subarray extended from that point.
4. Start accumulating again from the next element and repeat until the array ends.
5. Return maxSum, which stores the largest subarray sum encountered.

Remember: We are not checking every possible subarray separately. We use the running sum to efficiently find the best subarray sum in one traversal, giving us \(O(n)\) time complexity

- Above is Kandane algorithm
- Kadane’s Algorithm does NOT calculate the sum of all possible subarrays. 
- It skips subarrays that cannot help us find a better maximum sum.

function maxSumSubArray(arr){

  let maxSum = -Infinity;
  let sum = 0;

  for(let i=0;i<arr.length;i++){
    sum += arr[i];

    if(sum > maxSum){
      maxSum = sum;
    }
    if(sum < 0){
      sum = 0;
    }
  }
  console.log(maxSum);
}
